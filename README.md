# Arirang — сайт

Обновлённая главная страница arirangcompany.com: статический сайт без сборки (HTML + CSS + JS).

## Файлы

- `index.html` — вся страница
- `styles.css` — оформление
- `script.js` — номера телефона и WhatsApp, отзывы, форма. **Настройки в самом начале файла.**
- `og.png` — картинка-превью для ссылок в WhatsApp и Telegram
- `favicon.svg` — иконка вкладки

## Как поменять частые вещи

- **Номер телефона или WhatsApp:** `CONFIG` в начале `script.js`. Видимый текст номеров находится в блоке «Контакты» в `index.html`.
- **Добавить отзывы:** заполнить массив `REVIEWS` в `script.js`. Блок «Отзывы» появится на сайте сам.
- **Цены:** поиск по `$` и `₸` в `index.html`.

## Заявки

Форма не хранит данные: она собирает сообщение и открывает WhatsApp на номере из `CONFIG.whatsapp`.

## Деплой

Подключить репозиторий к Vercel как статический проект, без настроек сборки.
